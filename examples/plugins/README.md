# Example plugins

Small, real plugins to use or start from. Install one in Orbit with Settings,
Plugins, Install, and the address in its README. How plugins work:
[docs/PLUGINS.md](../../docs/PLUGINS.md).

| Plugin | Language | Shows |
| --- | --- | --- |
| [env-guard](env-guard) | TypeScript | A `before_tool` hook that sends anything touching secrets files to you, in every mode |
| [standup](standup) | Python | A read-only tool and a slash command that hands a task to Claude |
