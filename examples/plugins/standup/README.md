# Standup

An Orbit plugin. Type `/standup` in a workspace with a git repository and
Claude writes your standup from the commits since yesterday: Yesterday, Today,
Blockers. Settings: how far back to look, and whose commits.

Install: Settings, Plugins, Install, and paste

```
https://github.com/Elchi-dev/Orbit#main:examples/plugins/standup
```

A Python plugin with one tool and one command, in `main.py`. Needs `python3`
and `git`.
